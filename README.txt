DAYMARK LEARNING — FREE HTML TEMPLATE 1.0.0

One complete editable HTML landing page. HTML, CSS and vanilla JavaScript. No React,
Vite, npm install, account, external CDN or build step is required.

RUN LOCALLY
Unzip and open index.html. For realistic clipboard/asset behavior, use a static
HTTP server. With Python installed: python -m http.server 4216 --bind 127.0.0.1
Open http://127.0.0.1:4216/ and stop with Ctrl+C. All runtime assets are local.

CUSTOMIZE
Edit content in index.html. Tokens/responsive rules: assets/css/daymark.css.
Subject filters, navigation, FAQs and draft review: assets/js/daymark.js.
Keep filter data-subject keys and form subject radio values consistent. Original
book/pencil illustration and mark are editable SVG in assets/img/. Replace sample
business details, teaching scope and privacy information before a real launch.

DOMAIN-ROOT UPLOAD
Upload index.html and the full assets/ directory alongside it to public_html or
the host's public root. Retain LICENSE, notices and licenses/ with distribution.
No SPA/server rewrite is required. Use HTTPS for clipboard access; verify every
CSS/JS/font/image URL after upload. Hosting/domain/services are not included.

HOSTING IN A SUBFOLDER
Upload the same files to e.g. /daymark/. Internal URLs are relative, so no base or
build adjustment is needed. Visit the trailing-slash directory URL.

FUNCTIONAL SCOPE
Filters show real matching subject cards/counts; a card action selects the enquiry
subject. The form creates an explicitly UNSENT draft for review/edit/copy. Nothing
is transmitted, stored, booked, paid or taught. There is no scheduling, parent
account, payment or teaching backend. Use adult contact details/broad goals only;
never collect children's names, dates of birth, school records or sensitive data.
A real service needs secure server validation, spam controls and proper privacy
handling. Never replace the demo with a simulated sent/booking-success message.

ACCESSIBILITY / FALLBACKS
Without JS, page links, subject content and native details/summary FAQs work; the
draft form stays disabled with an explanation. Enhanced desktop Lenis has one
clock and local menu scrolling. Native touch/reduced motion, keyboard scrolling,
direct scrollbar dragging and mobile Escape/focus containment/return remain.
